# 作業ログ（警報等通知ダッシュボード）

## 2026-10-24

### 目的
リハビリテーション科（兵庫県小野市の病院）向けに、通勤に影響する情報（気象警報・鉄道運行情報・今後の見込み）をまとめて確認できるダッシュボードを作る。最終的には、自動取得した情報を BAND に投稿する。

### 決まった要件
- 対象地域：小野市・三木市・加東市・加西市・西脇市・多可町／神戸市西区・垂水区（＋北区）／加古川市・高砂市・姫路市・福崎町・三田市
- 気象：警報・注意報の発表状況と解除見込み。休校・休園の判定は現時点では行わない（基準が今後変わる可能性があるため）
- 鉄道：JR加古川線、神戸電鉄、JR神戸線（姫路〜三ノ宮）
- BAND：運用中のバンドに投稿。投稿対象は警報の発表・解除と運休の発生・再開。24時間投稿する
- 端末：スマホでの閲覧が中心
- GAS：他の用途で使っているため、使用量を節約したい

### 技術メモ
- 気象庁は2026/5/29から「新たな防災気象情報」に移行した。旧URL `bosai/warning/data/warning/280000.json` は 2026-05-26 で更新が止まっている → 新形式のデータへの対応が必要
- JR西日本：`train-guide.westjr.co.jp/api/v3/area_kinki_trafficinfo.json`（非公式）。加古川線は列車走行位置の対象外だが、運行情報は近畿エリアの情報に含まれる見込み（要確認）
- 神戸電鉄：https://www.shintetsu.co.jp/railinfo/ のページ内容を読み取る
- ブラウザから直接取得すると CORS で拒否されるため、取得を担当するサーバー側の仕組みが必要

### 実施内容
- v0.1.0：デモ用ダッシュボードを作成（index.html / style.css / app.js / demo-data.js）。データはすべて架空
  - シナリオ切替（平常時・台風接近・大雪）、総合ステータス、地域カード（タップで詳細表示、★でマイ地域登録）、運行情報、解除見込みタイムライン、5日先までの警報級の可能性、BAND投稿のプレビュー

### 2026-10-24（続き）気象庁データの調査
- 方針：気象庁データを基本とする。Yahoo!天気等は取得せず、市町ごとの詳細リンクのみ設置する（規約・安定性の理由）
- 方針：デモ版（ルート直下の index.html 等）は残す。実装は `実装版/` で行う（style.css・index.html・app.js・demo-data.js をコピー済み）。`実装版/sample-data/` に取得サンプルを保存

#### 取得先（すべて認証不要、2026-10-24 に取得を確認）
| 用途 | URL |
|---|---|
| 警報・注意報（兵庫県） | `https://www.jma.go.jp/bosai/warning/data/r8/280000.json` |
| 時系列の見通し（明日まで） | `https://www.jma.go.jp/bosai/warning_timeline/data/280000.json` |
| 警報級の可能性（5日先まで） | `https://www.jma.go.jp/bosai/probability/data/probability/r8/280000.json` |
| 市町村コード表 | `https://www.jma.go.jp/bosai/common/const/area.json`（class20s） |
- 旧 `warning/data/warning/280000.json` は 2026-05-26 で停止。新形式は `data/r8/`（令和8年の意味。年度が変わるとパスが変わる可能性があるため、パスは設定値にし、404時に気づける仕組みを入れる）

#### 警報・注意報データの構造
- ルートは配列。要素は「発表単位の電文」（dataTypeCode VPWW55〜61）で、**現在の状態そのものではなく、種別ごとの最新電文の集まり**
- 現在の状態は、(市町コード, 種別コード) ごとに reportDatetime が最新の電文を採用し、status が「解除」でないものを有効とみなして組み立てる（小野市で JMA 公式ページの表示と一致することを確認済み。ただし警報級が出ている場面では未検証）
- `class20Items` が市町村単位。`kinds` に code と status（発表／継続／解除／警報から注意報／危険警報から注意報 等）。code が無く「発表警報・注意報はなし」の場合は発表なし
- 危険度の区分（significancyPart の code）：20・21=注意報、30・31=警報、40・41=危険警報、50・51=特別警報（コンソール上の定義と実データからの推定）
- 新体系で「危険警報」が追加（旧：注意報・警報・特別警報の3段階）。デモ側の区分の見直しが必要
- 種別コードの意味（実データの見出し文からの推定。要確認）：03=大雨警報、05=暴風警報、07=波浪警報、10=大雨注意報、14=雷、15=強風、16=波浪、20=濃霧、21=乾燥、24=霜、29=土砂災害（注意）、48=危険警報（解除時のみ確認）、49=土砂災害（警戒レベル4相当）
